# API Tests
Автотесты для тестового задания.
Всего 19 тестов.

## Запуск
### 1. Запустить приложение
В отдельном терминале:
java -jar -Dsecret=qazWSXedc -Dmock=http://localhost:8888/ internal-0.0.1-SNAPSHOT.jar

### 2. Запустить тесты
mvn clean test

### 3. Открыть отчёт
mvn allure:serve
Отчёт откроется в браузере автоматически. Содержит описания сценариев, тела запросов и ответов.
